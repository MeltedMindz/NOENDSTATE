## #help

**Pinned — before you post**

One issue per thread, with what you expected, what happened, and a screenshot
if you have one. The team and moderators answer here, in public.

Nobody from NO END STATE will DM you to "help." Anyone who does is a scammer
— screenshot it and post it in #scam-reports.

vulnerabilities, do NOT post publicly — use the security contact on
noendstate.com.

## #scam-reports

**Pinned — how to report**

Seen a fake NO END STATE account, server, mint page, or a suspicious DM?
Post it here: screenshot plus the link or username. Security triages every
report.

Ground truth for checking yourself: the only live official surfaces are
noendstate.com and github.com/MeltedMindz/NOENDSTATE. There is no official
X or Telegram yet. There is no contract and no mint. The team never DMs
first and never asks for seed phrases.

If you already signed something or shared a seed phrase: assume the wallet
is compromised, move remaining assets from a clean device now, and then
report here — we will flag the pattern for others, but we cannot recover
funds.
