# Pinned post

Options for the standing pinned post — what a stranger sees first when they
check whether an account is really us. It must carry identity, the site, and
the safety facts in one screen. At launch, the launch thread's first post is
pinned; one of these replaces it once the launch cycle passes.

## Option A — identity plus safety (recommended)

```
NO END STATE. Founded once. Building indefinitely.

An onchain studio keeping a permanent public record: noendstate.com

Facts that don't change: we never DM first. We never ask for seed phrases. No contract addresses are published — any mint link is a scam until the site says otherwise.
```

## Option B — record-first

```
A permanent record of an unfinished company.

Every event, numbered and public: noendstate.com/chronicle

STATE ZERO marks the founding cohort. Minting is not active and no contract exists — noendstate.com is the only source of truth, and we never DM first.
```

## Option C — short

```
Founded once. Building indefinitely.

Everything real is at noendstate.com. We never DM first, never ask for keys, and no contract addresses exist. Verify everything against the site.
```

## Rotation rules

- The pin changes rarely: launch thread at launch, then a standing option,
  swapped only for active security announcements
  (`community/x/security-announcement-template.md`) and restored after.
- The pin always contains "noendstate.com" and "never DM first" in some
  form. If an edit drops either, the edit is wrong.
- If STATE ZERO terms are ever published, the pin is updated the same hour
  the site is — stale safety claims are their own incident.
