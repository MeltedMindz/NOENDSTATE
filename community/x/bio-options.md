# X bio options

Eight variants, all within X's 160-character bio limit. Character counts
noted; recount after any edit. Voice rules apply: no exclamation marks, no
crypto slang, no promises.

The profile link is always `https://noendstate.com` and is set in the link
field, not spent inside the bio.

## Option 1 — recommended

```
Founded once. Building indefinitely. / An onchain studio. / STATE ZERO records everything that follows.
```
103 chars. The core line, the category, and the cohort in one breath.
